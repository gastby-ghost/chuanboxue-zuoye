## 一、检验力与敏感性分析（G*Power 参数）

**为什么用敏感性分析（sensitivity）而非"预期效应量"**：本领域尚无可靠的目标效应量先例，硬填一个自己不信的 d 只会制造虚假的检验力。敏感性分析问的是相反的问题——**"这个样本能检出多大的效应"**，这个答案是可以对读者负责的。

### 1.1 H1（组间 t 检验）

| G*Power 填写项 | 值 |
| --- | --- |
| Test family | t tests |
| Statistical test | Means: Difference between two independent means (two groups) |
| Type of power analysis | **Sensitivity**（给定 N 求可检出 d） |
| Tails | Two |
| α err prob | .05 |
| Power (1−β) | .80 |
| Allocation ratio N2/N1 | 1 |
| **输入 Total sample size** | **150** |

**结果**：可检出 **d ≈ 0.46**。（解析校验：`(1.96+0.84)·√(2/75) = 0.457`，一致。）

### 1.2 三种检验各自吃多少样本

| 要检验的东西 | 方法 | N=150（每组 75）能否胜任 |
| --- | --- | --- |
| 组间差（H1） | 两独立样本 t | ✅ 可检出 d ≥ 0.46 |
| **两结局效应方向分离（H2）** | 配对 bootstrap 的 d₁−d₂ | ⚠️ **只能检出 Δd ≳ 0.65**（模拟实测 CI 半宽约 ±0.45） |
| **情感极化"未抬高"（H2 的等效版）** | TOST，等效边界 d = 0.20 | ❌ 需每组约 **310** 人 |

> **必须写进预注册的一句话**：H2 的"方向分离"在 N=150 下只有中等检验力，**H2 因此按探索性假设处理**——报效应量、CI 与贝叶斯因子，不作"已证明无效应"的断言。
>
> **为什么不能靠"p > .05"支持 H2**：不显著只是"没有证据说明有差"，不是"有证据说明没差"。要断言"未抬高"必须跑等效检验（TOST）并事先声明等效边界（本方案取 d = 0.20 的小效应界）。而 TOST 对 d 0.2 的边界需要约 310 人/组，超出本作业规模——所以**诚实的做法是承认检验力不足，而不是把不显著说成等效**。

### 1.3 提高检验力的三条路（按性价比排序）

1. **把主要结局收窄为一个**（见第三节），放弃对三个结局同时校正——免费回收一部分检验力。
2. **用配对/重复测量结构**：若预算允许，做**两次测量**（暴露前后），把感知极化的分析改为混合设计，被试内成分大幅压缩误差。
3. **上调样本**：招募顺利时上探 200（见 `研究设计.md` 第七节）。

## 二、预注册模板（可直接粘贴到 OSF）

> 以下为逐节可填文本；`[方括号]` 处按实际替换。

**1. 研究问题**
AI 搜索能否缓解舆论场中的多元无知，并将这一认知纠正传导为意见表达的改变？（RQ1 感知极化／RQ2 情感极化／RQ3 意见表达）

**2. 假设**
- H1：AI 搜索（vs 无）降低感知极化（−）
- H2：AI 搜索不降低、甚至抬高情感极化；感知极化与情感极化的效应出现**方向分离**（＝／＋）
- H3a：感知极化降低意见表达意愿（−）
- H3b：感知极化提高表达的对立化程度（＋）
- H3c：感知极化与情感极化并行中介"AI 搜索 → 意见表达"；情感中介削弱（不必然反转）认知中介的负向间接效应

**3. 设计**
单因子被试间，两水平：AI 搜索（智搜多元观点整合截图）vs 对照（同议题平台原始评论流截图）。两材料同一议题、同等信息量。测量顺序固定，不随机化（感知判断先于表达任务）。

**4. 样本与样本量**
目标**有效** N = 150（每组 75）；预留 15% 流失，招募约 175。敏感性分析（α=.05，power=.80，双尾）：可检出 d ≈ 0.46。

**5. 排除标准**（**在查看数据前锁定**）
- S1 微博使用频率 ≤ 2；
- 停留时间 < 10 秒；
- AC1 注意力检查未通过；
- 同一 IP/设备重复提交（保留首次）。

**6. 主要与次要结局**
- **主要结局：感知极化 `perceived_gap`**（对应 RQ1，全设计的立足点）
- 次要结局：情感极化 `affect_out`、意见表达意愿 `willingness`、表达对立化程度 `incivility`、比例估计偏差 `pct_bias_opp`

> 与 `研究设计.md` 原稿的差异：原稿建议把"表达的对立化程度"设为主要结局。本方案改为 `perceived_gap`，理由是 RQ1 是设计的立足点、H2 的检验又以它是参照。**若指导老师要求把理论缺口 H3 立为主要结局，可换回**，此时 H1／H2 降为次要结局。

**7. 分析计划**（详见第三节、第八节）

**8. 缺失值**：完整案例为主；多重插补作敏感性分析。

**9. 停止与数据检验**：收满即停，不做期中检视（无数据窥探）。

## 三、分析计划与判定规则

**一律报效应量与 95% CI；不做 p 值单点判断。**判定如下（预先锁定，事后不改）：

| 假设 | 检验 | 判定为"支持"的条件 |
| --- | --- | --- |
| **H1** | Welch 独立样本 t | Cohen's **d < 0 且 95% CI 不含 0** |
| **H2** | ① 配对 bootstrap 的 d₁−d₂；② 情感极化单独的 CI；③ TOST＋BF（辅助） | ① **CI 上界 < 0**（感知极化降得比情感极化多）；或 ② 情感极化 CI **方向为正**（不降反升） |
| **H3a** | OLS：`willingness ~ perceived_gap` | **b < 0 且 CI 不含 0** |
| **H3b** | OLS：`incivility ~ perceived_gap` | **b > 0 且 CI 不含 0** |
| **H3c** | 并行中介 bootstrap（5000 次） | **间接效应 X→M1→Y 的 CI 不含 0**；对比（M1−M2）CI 不含 0 则支持"认知中介更强" |

**关于 H3c 的"削弱但不必然反转"**：这一措辞的可操作化就是**间接效应之差（contrast）**——`a₁b₁ − a₂b₂`。若该差 CI 不含 0，即为"两条中介路径强度不同"的直接证据；若含 0，只能说方向分离不足，不能说"没有削弱"。这个落点必须在预注册里写定。

**关于 H3a／H3b 与 H3c 的关系**：H3a／H3b 检验的是模型中的 **b 路径**（M→Y），H3c 检验的是**间接效应**（a·b）。三者共用同一批系数，不是三次独立检验。

### 多重比较策略

- **主要结局 `perceived_gap`**：单项检验，**不校正**（预注册指定）。
- **次要结局**：报 Benjamini-Hochberg 的 **q 值**（`tools/analysis_pipeline.py` 第四节已自动给出），同时保留未校正 p 与效应量供读者判断。
- 不采用 Bonferroni：它在三、四个结局上过度保守，会把中等效应也误杀。

## 四、稳健性与缺失值

| 项目 | 做法 |
| --- | --- |
| 协变量 | 立场强度 `stance_strength`、议题卷入 `issue_involve`、微博使用频率、教育；放入 ANCOVA／回归看系数是否稳定 |
| 稳健性检验 1 | 换用 `perceived_bias`（减去基准）重跑 H1，看方向是否一致 |
| 稳健性检验 2 | 把 `incivility` 拆成 `C_written`（是否写）与 `C_len`（字数）两个成分分别检验 |
| 稳健性检验 3 | 仅对通过注意力检查的样本重跑（**报告两版结果**，主报告用全样本 ITT） |
| 缺失值 | 完整案例为主；SPSS 多重插补（20 个数据集）作敏感性分析 |
| 异常值 | 不删除；报告含与不含极端值的两版系数 |

**操纵检查的处理规则**（预先锁定）：M1/M2 的报告属**描述性**。若 M2 组间无差异，说明操纵未被察觉，须在讨论中如实报告，**但不据此剔除被试**——按操纵检查剔人会破坏随机化、引入选择偏差。

## 五、零结果与反向结果的解释预案（**必须预写**）

| 结果形态 | 结论写法 | 对话文献 |
| --- | --- | --- |
| H1 null、H2 null | AI 搜索的整合呈现**不足以**校准感知，认知层即失效 | Geiger et al. 2025（δ=0.05）；Vlasceanu et al. 2024（63 国） |
| H1 成立、H2 反向（情感极化升） | **认知与情感分离**：降温器只冷却了"想象"，没冷却"情绪"，反而点燃 | Levendusky & Malhotra 2016；Bail et al. 2018 |
| H1 成立、H2 null | 矫正路径成立、未观察到大范围回旋镖 | Lees & Cikara 2021；Sparkman et al. 2022 |
| H1、H2 均指向降温，H3 亦成立 | 算法化社会规范干预在中文语境有效 | Piccardi et al. 2025 |
| H1 成立但 H3 null | **复现"认知—行为缺口"**：纠正误判难以传导为表达改变——这本身是本研究最有价值的零结果 | Miller 2023；Vlasceanu et al. 2024 |

> 最后一行正是本设计的理论缺口所在：H3 为零不等于研究失败，而是**对缺口的直接证据**。这一句要写进预注册，免得事后被动。

## 六、数据准备与变量计算（SPSS）

1. **计算变量**（Transform → Compute Variable）
   - `perceived_gap = ABS(P_sup - P_opp)`
   - `willingness = MEAN(E_1, E_2, E_3)`
   - `stance_strength = ABS(P_self - 4)`
   - `perceived_bias = perceived_gap - actual_gap`（`actual_gap` 由第一步内容分析给出，用常量或按议题合并）
2. **信度**（Analyze → Scale → Reliability Analysis）：对 `E_1–E_3` 报 Cronbach's α。
3. **描述统计**：分组的均值、SD、n。

## 七、SPSS + PROCESS 逐步操作

| 假设 | 路径 | 关键设置 |
| --- | --- | --- |
| H1／H2 | Analyze → Compare Means → **Independent-Samples T Test** | 检验变量分别放 `perceived_gap`、`affect_out`、`willingness`、`incivility`；分组变量 `group`（0/1）。**SPSS 27+ 勾选 "Estimate effect sizes"** 取 Cohen's d；旧版按 `d = (M₁−M₂)/SD_pooled` 手算 |
| H3a／H3b | Analyze → Regression → **Linear** | 因变量 `willingness`／`incivility`，自变量 `perceived_gap`；读 B、SE、t、p、95% CI |
| H3c | Analyze → Regression → **PROCESS v4.x（Hayes）** | Model **4**；X = `group`，M1 = `perceived_gap`，M2 = `affect_out`（**并行中介**），Y = `willingness`（再跑一遍 `incivility`）；Options 勾选 **Show total effect / Indirect effects / Pairwise contrasts between indirect effects**；**Bootstrap 5000，95% 百分位 CI**（默认偏差校正亦可，预注册里写定） |
| 稳健性 | 同上，把协变量填入 PROCESS 的 covariates 或线性回归的"Block 1" | 看系数方向是否稳定 |

**TOST 与贝叶斯因子**：SPSS 无内置。二选一——
- 用 **JASP**（免费，图形界面）→ Bayesian t-test（`BF₁₀`）与 TOST；
- 或直接用 `tools/analysis_pipeline.py`（自带 TOST 与 BF）。

## 八、可复现实现：`tools/analysis_pipeline.py`

一行命令跑通全流程（清洗→计分→信度→操纵检查→t 检验→TOST/BF→回归→并行中介→FDR 校正）：

```bash
python3 -m pip install numpy pandas scipy statsmodels

# 没有真实数据：先生成模拟数据、把整条流水线跑通
python3 tools/analysis_pipeline.py --simulate

# 有真实数据（列名见《测量工具.md》计分表）
python3 tools/analysis_pipeline.py --data data/clean.csv
```

输出写入 `outputs/report-<日期>.txt`。

**它实现了哪些在本作业里最容易出错、最容易被人挑的地方**

| 设计上的坑 | 脚本里的对应实现 |
| --- | --- |
| H2 用"不显著"当证据 | `tost()`：真正的等效检验；`bayes_factor_t()`：BIC 近似的 BF₁₀ |
| "方向分离"没有检验落点 | `paired_d_diff_ci()`：**配对** bootstrap 求 d₁−d₂ 的 CI（利用两结局相关，而非各自独立） |
| 多重比较含糊 | `bh_q()`：Benjamini-Hochberg 的 q 值 |
| 中介的间接效应与对比 | `parallel_mediation()`：a、b、c′、两条间接效应、以及 contrast（a₁b₁−a₂b₂），Bootstrap 5000 |
| 序列化能否被他人复现 | 固定 `SEED`；`--simulate` 让任何人无需数据即可复算 |

**流水线自检样例**（模拟数据 N=150，**仅为验证代码正确，不是研究结论**）：

```
perceived_gap  Welch t(142.7) = −2.37, p = .019   d = −0.39  95% CI [−0.71, −0.08]
affect_out     TOST p = .137（尚不能判定等效；需每组约 310 人）
               d(感知) − d(情感) = −0.366  95% CI [−0.824, +0.085] → 分离未获支持
间接 X→M1→Y    = +0.113  95% CI [+0.013, +0.241] *
```

**R 用户**：同一流程可用 `psych::alpha`（信度）、`TOSTER::t_TOST`（等效）、`BayesFactor::ttestBF`（BF）、`lavaan` 或 `mediation::mediate`（并行中介，`bootstrap = 5000`）实现，参数与上表一一对应。
